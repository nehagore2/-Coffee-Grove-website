THE COFFEE GROVE — PROFESSIONAL REDESIGN
========================================

Design direction:
- Modern, minimal and professional editorial coffee brand.
- Original layout inspired by clean specialty coffee design, not a copy of another site.
- Warm ivory, charcoal, muted olive and coffee tones.
- Manrope + DM Sans + Playfair Display typography.
- Responsive desktop, tablet and mobile layouts.
- Vertical, readable HTML, CSS and JavaScript source files.

Included pages:
- index.html — Home
- estate.html — Our Estate
- shop.html — Coffee Collection
- journal.html — Journal
- contact.html — Contact

Shared files:
- css/style.css — all visual styling and responsive rules
- js/script.js — mobile navigation, scroll reveals, persistent demo cart and form feedback
- assets/ — extracted from the uploaded project ZIP

How to run:
1. Extract this ZIP.
2. Open the Coffee Grove folder in VS Code.
3. Open index.html with Live Server.
4. Keep all files and folders in their existing positions.
5. Check the site locally before publishing it to GitHub Pages.

Important:
- Product prices are demo values; confirm the actual products and prices before launch.
- The shopping bag adds/removes products and stores the bag in localStorage.
- Checkout is a demo only. No payment provider is connected.
- The contact form validates fields and displays confirmation in the browser, but does not send an email.
- Replace hello@thecoffeegrove.example and the sample location with verified company contact details.
- Google Fonts needs an internet connection. Fallback fonts are included.
